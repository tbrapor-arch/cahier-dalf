# Cahier DALF C1·C2

Application web pour préparer le DALF C1 et C2 : 190 structures clés, 1 360 mots et expressions en 27 thèmes, 14 textes d'écoute avec transcription synchronisée, quiz, méthode de l'écrit et examen blanc au format officiel.

**Ouvrir l'app :** https://tbrapor-arch.github.io/cahier-dalf/

Sur téléphone, menu du navigateur → « Ajouter à l'écran d'accueil » pour l'installer comme une application. Elle fonctionne ensuite hors ligne. La progression est enregistrée sur l'appareil.

## Structure

- `index.html` : toute l'application (contenu, styles et code)
- `manifest.webmanifest`, `icons/` : installation sur l'écran d'accueil
- `sw.js` : fonctionnement hors ligne. Incrémenter `VERSION` à chaque mise à jour.

Les exercices sont originaux, au format du sujet de démonstration officiel de France Éducation international.
